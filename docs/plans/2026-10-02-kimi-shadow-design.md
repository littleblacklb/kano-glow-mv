# 「君」的影子：用缺席表现君

## 为什么
这首歌讲的是对「君」放不下：想让你消失，却抱得更紧；你在我心里一点点融化、模糊，我却紧紧抓住。
画面里一直只有她一个人，所以作品读起来像"一个女孩的孤独"，而不是"放不下一个人"。
做法是不画出君，只画出君的缺席：她身边的地面上多一道没有人投下的影子。

## 规则
- **光在才在。** 影子需要有方向的光。君的影子只出现在有太阳的段落（夕暮、间奏、傷跡）和最后的雲間；
  太阳沉落时随光消失（对应「君を溶かして夜になるだけ」），夜和红墨段不出现。
- **跟着她的姿势变。** 她坐着时（sunset、play）是并肩坐着的影子，她站着时（hug、cling）是站在身旁的影子。
- **人物本身永远不出现**，只渲染影子。

## 位置与光
- 影子根部落在她左侧（朝光一侧）的空地上：站姿约 −0.05W，坐姿约 −0.08W，避开她的身体；
  根部高度用 `groundY` 在那一点的 x 上取值。
- 倾斜角和长度沿用该场景的 `shadow`（同一道光），所以两道影子平行倒向右边。
- 站姿的君比她高约 15%，坐姿和她差不多高。

## 时间弧线 `kimiAt(t)` → { presence, blur, dx 系数 }
| 时间 | 段落 | 君的影子 |
|---|---|---|
| 70–106s | 夕暮（坐） | 淡入，浓度和她的影子相同 |
| 106–131s | 间奏（坐） | 约 85% |
| 131–158s | 傷跡（站） | 约 60% |
| 158–166s | 太阳沉落 | 淡到 0 |
| 166–232s | 夜、红墨 | 0 |
| 232–238s | 雲間 | 约 90%，带 2–3px 模糊重新出现（滲む 靠模糊而不是变淡：50% 在暗色地面上看不见） |
| 238–248s | 「ぎゅっとしがみついた」 | 偏移 → 0，与她的影子重叠，模糊加深 |
| 248–252s | | 和她的影子一起淡去 |

## 代码结构
- `src/data/characterScenes.ts`：新增 `companion?: { id; dx; h }`（sunset/play/hug/cling），
  以及纯函数 `kimiAt(t)`，关键帧用 `interpolate`。
- `src/components/Character.tsx`：把影子渲染抽成 `<CastShadow>`，她和君共用；
  君只渲染 `<CastShadow>`，不渲染人物本体。
- 素材：`art/prompts/kimi-sit.txt`、`kimi-stand.txt`，通过 `art/gen.sh` 生成，
  选中的版本放进 `art/picked/`，再用 `scripts/key-characters.py` 抠图。

## 测试
- 166–232s 之间存在度为 0。
- 238s 之后偏移单调缩小到 0。
- 君的影子根部不和她的身体重叠。

## 验证
渲染 90s、120s、150s、163s、235s、242s、250s 的静帧，看影子的浓度、位置、模糊以及和她影子的关系，
并与 `a8a2b3a` 的画面做前后对比。
